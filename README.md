# AWS Cloud Architecture & CI/CD - Course Management System

## 專案簡介

本專案以 Flask 課程管理系統為實作案例，建置 AWS 雲端應用架構，整合 Docker、RDS、S3、Amazon Bedrock、CloudWatch 與 GitHub Actions，實現雲端部署、CI/CD 自動化、AI 課程推薦及系統監控。

## 核心技術

- Backend：Python、Flask、MySQL
- Container：Docker、Amazon ECR
- AWS Infrastructure：EC2、ALB、RDS、S3
- CI/CD：GitHub Actions、OIDC、AWS Systems Manager
- AI：Amazon Bedrock
- Monitoring：CloudWatch、SNS
- Security：IAM Role、Security Group

## 核心實作

- AWS EC2 + Docker 部署 Flask 應用
- ALB 與 Target Group 健康檢查
- RDS MySQL 與 S3 私有物件管理
- GitHub Actions 自動測試、建置與部署
- Amazon Bedrock AI 課程推薦
- CloudWatch 系統監控與 SNS 異常通知
